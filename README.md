# College Facility Booking System

A responsive web application designed to simplify the process of booking college facilities such as halls and laboratories.

## 🚀 Live Demo

[View Live Project](YOUR_NETLIFY_LINK)

## 📌 About the Project

The College Facility Booking System provides an easy-to-use interface for students and staff to view and book available college facilities.

The application is built with React.js and uses browser Local Storage to store and manage booking information.

## ✨ Features

- Responsive and user-friendly interface
- Facility booking system
- Hall and laboratory booking
- Booking data persistence using Local Storage
- Add and manage bookings
- Clean and simple UI
- Works across desktop and mobile devices

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- React.js
- Local Storage
